# First setup

Out of the box the device has this guide on it and nothing else. Setting it up
takes a couple of minutes.

## 1. Power it on

Connect the board over USB. It starts its own Wi-Fi network within a second or
two. There is no power button and no setup mode to enter.

## 2. Join its network

On a phone, tablet, or laptop, join the Wi-Fi network named `PocketWiki`. It is
open by default, so no password is needed. You may see a "no internet"
warning. That is expected, because the network only contains the library. Stay
connected to it.

## 3. Open the reader

Browse to `192.168.4.1`. You should see this
guide listed under your libraries. Tap an article and start reading.

## 4. Optional: connect it to your Wi-Fi

If you want the device to download packs by itself, open
`192.168.4.1/manage`, pick your 2.4 GHz
network, and enter its password. The device keeps its own access point running
while it is connected, so reading never depends on your network.

## 5. Optional: add the Android app

The app installs packs over Bluetooth, including several at once, and can set
up the Wi-Fi for you. See [the Android app](00010-android-app).

If anything does not work, [Troubleshooting](00016-troubleshooting)
walks through the usual causes.
